# М6 — Фильтрация сигналов (RC ФНЧ)

Одностраничный интерактивный сайт для исследования RC-фильтра нижних частот.

## Запуск

```bash
cd filter_app
pip install -r requirements.txt
python app.py
# → http://127.0.0.1:5000
```

## Возможности

| Раздел | Описание |
|---|---|
| **Теория** | Схема цепи, аналитическое выражение H(jω) через SymPy, дифференциальное уравнение |
| **АЧХ / ФЧХ** | Аналитический расчёт на логарифмической шкале частот |
| **Переходный процесс** | Численное решение ОДУ (RK45), визуализация включения гармоники |
| **Сравнение** | Измерение амплитуды и фазы установившихся колебаний vs аналитика |
| **Прямоугольник** | Прямоугольный сигнал → численный FFT vs аналитический спектральный метод |

## Параметры цепи

- R = 1 кОм, C = 1 мкФ → RC = 1 мс → **f_c ≈ 159 Гц**
- Дифференциальное уравнение: `RC·dU_out/dt + U_out = U_in(t)`
- Передаточная функция: `H(jω) = 1/(1 + jωRC)`
