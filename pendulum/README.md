# Физический маятник — моделирование, веб-интерфейс и сравнение с теорией

## Описание

Моделирование поведения физического маятника — твёрдого тела, подвешенного в поле тяжести. Программа использует численное интегрирование методом Рунге-Кутты 4-го порядка (RK4) для решения дифференциального уравнения колебаний.

## Теоретическая информация

### Уравнение движения

Физический маятник описывается дифференциальным уравнением:

```
I·θ'' + b·θ' + m·g·d·sin(θ) = 0
```

где:
- `θ` — угловое отклонение от положения равновесия
- `I` — момент инерции относительно оси подвеса
- `m` — масса тела
- `g` — ускорение свободного падения (9.81 м/с²)
- `d` — расстояние от оси подвеса до центра масс
- `b` — коэффициент вязкого трения

### Период колебаний

#### Малые колебания (sin θ ≈ θ)

Для малых углов отклонения период колебаний:

```
T₀ = 2π√(I/mgd)
```

#### Точная формула через эллиптический интеграл

Для произвольной начальной амплитуды θ₀:

```
T(θ₀) = 4√(I/mgd)·K(k)
```

где K(k) — полный эллиптический интеграл первого рода, k = sin(θ₀/2).

### Зависимость периода от амплитуды

При больших углах отклонения период увеличивается:
- При θ₀ = 30° период примерно на 1.7% больше, чем T₀
- При θ₀ = 60° период примерно на 7% больше, чем T₀
- При θ₀ = 90° период примерно на 18% больше, чем T₀

### Пресеты для различных форм тела

| Форма | Момент инерции I | Расстояние d |
|-------|-----------------|--------------|
| Стержень (подвес за конец) | mL²/3 | L/2 |
| Диск (подвес за край) | 3mR²/2 | R |
| Кольцо (подвес за край) | 2mR² | R |

### Энергия системы

- **Кинетическая энергия**: KE = ½Iω²
- **Потенциальная энергия**: PE = mgd(1 - cos θ)
- **Полная энергия**: E = KE + PE

При отсутствии трения (b = 0) полная механическая энергия сохраняется.

### Затухающие колебания

При наличии вязкого трения (b > 0):
- Колебания затухают со временем
- Энергия рассеивается
- Период колебаний незначительно изменяется для малых значений b

## Установка и запуск

### Требования

- Python 3.7+
- NumPy
- Matplotlib

### Установка зависимостей

```bash
pip install numpy matplotlib
```

### Запуск

```bash
cd pendulum
python pendulum.py
```

## Использование

При запуске программа запросит ввод параметров:

1. **Форма маятника**:
   - 1 — Стержень (подвешен за конец)
   - 2 — Диск (подвешен за край)
   - 3 — Кольцо (подвешено за край)
   - 4 — Пользовательские параметры

2. **Физические параметры**:
   - Масса m (кг)
   - Длина L или радиус R (м)
   - Для пользовательского режима: I и d

3. **Начальные условия**:
   - Начальный угол θ₀ (°)
   - Начальная угловая скорость ω₀ (рад/с)

4. **Коэффициент трения b** (0 для свободных колебаний)

5. **Параметры расчёта**:
   - Шаг интегрирования dt (с)
   - Длительность симуляции (с)

## Результаты

Программа выводит:
- Параметры маятника (I, m, d, b)
- Теоретический период малых колебаний T₀
- Измеренный средний период
- Отклонение от теории (%)
- Анализ сохранения энергии

Также строятся графики:
- Угловое отклонение θ(t)
- Угловая скорость ω(t)
- Энергия системы (KE, PE, E)
- Фазовый портрет (θ, ω)

Графики сохраняются в файл `pendulum_results.png`.
